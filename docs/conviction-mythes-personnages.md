# Mythologies (Crète, Asgard, Rome) : fiche de design

Vue le 2026-10-17 sur les IMAGES (vases, peintures, illustrations
traditionnelles, bustes antiques ; Google Images). Domaine public. Les
humains sont des bustes avec un costume (`ui/costumes.js`), le Minotaure est
de PROFIL comme les dieux à tête d'animal (`ui/egypte.js`). Initiales uniques
par enquête : Cassius, Calpurnia et Cicéron (C), Frigg et Freyja (F) ne
pouvaient pas aller ensemble ; Décimus, Lépide et Nanna sont aussi de l'histoire.

## « Le fil d'Ariane » : la Crète (facile, coupable Thésée)

| Personnage | Rôle | Vu en image |
|---|---|---|
| **Le Minotaure** | victime | tête de taureau brune, cornes qui montent en croissant, mufle clair, anneau au nez ; corps d'homme musclé. |
| **Thésée** | le héros d'Athènes, coupable | jeune, cheveux bruns bouclés courts, tunique courte rouge, baudrier d'épée. |
| **Ariane** | la princesse | longs cheveux noirs bouclés, bandeau d'or, robe crétoise bleue à volants ; la pelote de fil rouge. |
| **Dédale** | l'inventeur | vieil homme chauve, barbe blanche, tablier d'artisan, compas. |
| **Icare** | le fils de Dédale | jeune, cheveux blonds bouclés, les AILES de plumes collées à la cire dans le dos. |
| **Minos** | le roi de Crète | barbe noire bouclée, couronne de lys à plumes, manteau pourpre. |
| **Pasiphaé** | la reine | cheveux noirs bouclés relevés, diadème, robe safran à volants. |
