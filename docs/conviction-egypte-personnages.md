# Égypte : fiche de design des personnages

Vue le 2026-10-17 sur les IMAGES (peintures de tombes et de papyrus, Google
Images), pour l'enquête « Le coffre d'Osiris » (collection Mythologies).
Domaine public : aucun risque de retrait. Les dieux à tête d'animal sont de
PROFIL tournés vers la droite, comme dans la peinture égyptienne et comme nos
créatures (`ui/bete.js`) ; les autres sont des bustes avec un costume.

| Personnage | Rôle | Vu en image |
|---|---|---|
| **Osiris** | le roi d'Égypte, victime | peau VERTE ; haute couronne blanche (atef) en bulbe, une plume d'autruche de chaque côté ; barbe postiche tressée, recourbée vers l'avant ; linceul blanc ; crosse et fléau croisés sur la poitrine. |
| **Seth** | le frère jaloux, coupable | tête de « l'animal de Seth » : long museau qui se courbe vers le bas, deux grandes oreilles DROITES au bout CARRÉ ; souvent rouge ; coiffe rayée bleue. |
| **Isis** | l'épouse d'Osiris | perruque noire droite ; le hiéroglyphe du TRÔNE posé sur la tête ; robe blanche ajustée ; large collier d'or, de bleu et de rouge ; trait de khôl. |
| **Nephthys** | la sœur d'Isis | même allure qu'Isis ; sur la tête le hiéroglyphe de la MAISON surmontée d'une corbeille. |
| **Anubis** | le gardien des tombeaux | tête de chacal NOIRE, oreilles hautes et pointues, museau long et fin ; coiffe rayée or et bleu ; large collier. |
| **Thot** | le scribe des dieux | tête d'IBIS sombre, long bec fin et courbé vers le bas ; coiffe rayée bleu et vert ; tient un calame. |
