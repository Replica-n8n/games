# Star Patrol : versions

Numéro en trois chiffres, `majeur.mineur.correctif`, écrit UNE fois dans
`patrouille/sw.js` (`VERSION = "patrouille-x.y.z"`) : il nomme le cache hors
ligne et s'affiche sur la carte (« Version x.y.z »).

- **majeur** : une ancienne sauvegarde ne marcherait plus ;
- **mineur** : du nouveau (planètes, missions, armes, fonctions) ;
- **correctif** : corrections et retouches.

| Version | Date | Contenu |
|---|---|---|
| 1.0.0 | 2026-10-21 | Première version en ligne, en formes simples : la Jungle complète (6 missions, la mission secrète, le Grand Caméléon), le Hangar, bonus et munitions qui ne se gaspillent pas, difficulté qui monte d'une mission à l'autre |
| 1.0.1 | 2026-10-21 | Le jeu s'appelle Star Patrol |
