# Star Patrol : versions

Numéro en trois chiffres, `majeur.mineur.correctif`, écrit UNE fois dans
`patrouille/sw.js` (`VERSION = "patrouille-x.y.z"`) : il nomme le cache hors
ligne et s'affiche sur la carte (« Version x.y.z »).

- **majeur** : une ancienne sauvegarde ne marcherait plus ;
- **mineur** : du nouveau (planètes, missions, armes, fonctions) ;
- **correctif** : corrections et retouches.

| Version | Date | Contenu |
|---|---|---|
| 1.0.0 | 2026-10-21 | Première version en ligne, en formes simples : la Jungle complète (6 missions, la mission secrète, le Grand Caméléon), le Hangar, bonus et munitions qui ne se gaspillent pas, difficulté qui monte d'une mission à l'autre |
| 1.0.1 | 2026-10-21 | Le jeu s'appelle Star Patrol |
| 1.1.0 | 2026-10-21 | Le Hangar s'ouvre après chaque mission (et après une défaite), une pastille dit quand un achat est possible ; prix relevés (60, 130, 220 ; cœurs 100, 200, 320) : environ un achat par mission, jamais tout au maximum avant le boss ; tir de base amélioré moins fort ; missions 4 à 6 un peu plus dures pour un joueur équipé |
| 1.2.0 | 2026-10-22 | La Jungle peinte : on survole un sol différent à chaque mission (prairie, fougères, rivière, canopée, marais, nid, temple), les arbres sont vus de haut ; messages en haut sous les cœurs (le doigt les cachait) ; plafond pour le module, avec un trait qui s'allume quand on s'y appuie |
| 1.3.0 | 2026-10-22 | Le Désert : le rover, ses rochers (on s'y abrite), le sable mou et les tremplins ; 7 ennemis (vautours, boules d'herbe, scarabées des sables, scorpions, cactus, taupes, ver des sables) ; 6 missions, la mission secrète « La cité enfouie » et le Scarabée géant ; un sol peint par mission ; la nouvelle arme Grosses bulles ; le rover monte aussi haut que l'avion ; réglage de test « Toutes les missions ouvertes » |
| 1.4.0 | 2026-10-22 | Les tremplins servent : un arc de cristaux qu'on n'attrape qu'en sautant, des murailles de rochers qu'on ne passe qu'en sautant, un tremplin devant les rochers qui roulent du Scarabée géant, et un atterrissage qui sonne les ennemis au sol ; saut plus long (80 images) |
