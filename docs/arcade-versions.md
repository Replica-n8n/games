# L'Arcade : versions

Numéro en trois chiffres, `majeur.mineur.correctif`, écrit UNE fois dans le
`sw.js` racine (`VERSION = "arcade-x.y.z"`) : il nomme le cache hors ligne de la
page d'accueil. L'arcade ne l'affiche nulle part.

- **majeur** : une ancienne sauvegarde ne marcherait plus (aucun jusqu'ici) ;
- **mineur** : du nouveau (un jeu qui rejoint l'arcade, une fonction) ;
- **correctif** : corrections et retouches.

Jusqu'au 2026-10-17, le numéro était un compteur (`arcade-1` à `arcade-3`),
augmenté à chaque publication. Correspondance, reconstruite d'après l'historique :
