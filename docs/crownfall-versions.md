# Crownfall : versions

Nom de code, le titre reste à trouver. Numéro en trois chiffres,
`majeur.mineur.correctif`, écrit UNE fois dans `crownfall/sw.js`
(`VERSION = "crownfall-x.y.z"`) : il nomme le cache hors ligne et l'accueil
l'affiche (« Version x.y.z »).

- **majeur** : une ancienne sauvegarde ne marcherait plus (`FORMAT` du moteur) ;
- **mineur** : du nouveau (règles, écrans) ;
- **correctif** : corrections et retouches.

| Version | Date | Contenu |
|---|---|---|
| 1.0.0 | 2026-11-14 | Le jeu solo d'après la maquette « salle du trône » : douze figures nommées, attaque animée, riposte à l'écu (toucher ou glisser), Jokers et médailles, règles, partie reprise, installable et hors ligne |
| 1.0.1 | 2026-11-16 | La riposte partait avant que l'écu soit rempli : elle s'annonce, et le coup ne frappe l'écu qu'à « Encaisser » |
| 1.0.2 | 2026-11-16 | Journal de test (hors ligne seulement, jamais sur github.io) : chaque coup noté dans le navigateur, à copier depuis la pause ou l'accueil |
