# Dig Zen : versions

Numéro en trois chiffres, `majeur.mineur.correctif`, écrit UNE fois dans
`dig/sw.js` (`VERSION = "dig-x.y.z"`) : il nomme le cache hors ligne et s'affiche
en bas de l'étagère (« Version x.y.z »).

- **majeur** : une ancienne sauvegarde ne marcherait plus ;
- **mineur** : du nouveau (fouilles, chaînes, outils, écrans) ;
- **correctif** : corrections et retouches.
