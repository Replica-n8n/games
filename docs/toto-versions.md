# toto : versions

Numéro en trois chiffres, `majeur.mineur.correctif`, écrit UNE fois dans
`toto/sw.js` (`VERSION = "toto-x.y.z"`) : il nomme le cache hors ligne. Le jeu
ne l'affiche nulle part.

- **majeur** : une ancienne sauvegarde ne marcherait plus (aucun jusqu'ici) ;
- **mineur** : du nouveau (zones, créatures, habits, écrans) ;
- **correctif** : corrections et retouches, y compris une créature redessinée.

Jusqu'au 2026-10-17, le numéro était un compteur (`toto-1` à `toto-34`),
augmenté à chaque publication. Correspondance, reconstruite d'après
