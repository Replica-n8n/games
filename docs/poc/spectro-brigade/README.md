# Spectro-Brigade — POC rail shooter 16 bits (PWA)

Déploiement : copier le contenu de ce dossier sur n'importe quel hébergement statique en HTTPS
(GitHub Pages, Netlify, Vercel, Cloudflare Pages…). Ouvrir l'URL sur mobile puis « Ajouter à l'écran d'accueil »,
ou utiliser le bouton INSTALLER (Chrome/Edge). Le jeu fonctionne ensuite hors ligne.

Test local : `python3 -m http.server 8000` dans ce dossier, puis http://localhost:8000

Commandes : viser au doigt/souris, maintenir pour tirer le rayon. Clavier : flèches + Espace, P = pause, M = son.
