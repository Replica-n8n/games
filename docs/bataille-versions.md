# La Bataille : versions

Numéro en trois chiffres, `majeur.mineur.correctif`, écrit UNE fois dans
`bataille/sw.js` (`VERSION = "Vx.y.z"`) : il nomme le cache hors ligne, s'affiche
sur l'écran titre (« Vx.y.z », le « V » est le choix de Julie depuis la V8) et
part avec chaque mesure anonyme vers `serveur-bataille/`.

- **majeur** : une ancienne sauvegarde ne marcherait plus (aucun jusqu'ici) ;
- **mineur** : du nouveau (règles, pouvoirs, écrans) ;
- **correctif** : corrections et retouches.

Jusqu'au 2026-10-17, le numéro était un compteur (`bataille-1` à `bataille-7`,
puis `V8` à `V12`), augmenté à chaque publication. Correspondance, reconstruite
d'après l'historique :
